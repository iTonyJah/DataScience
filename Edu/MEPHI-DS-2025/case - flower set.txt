9. Кейс: цветочный букет
Перед Вами стоит задача по созданию сервиса по формированию цветочных букетов с использованием технологий искусственного интеллекта для онлайн магазина цветов «iFlower.ru».

Базовая информация:
Для заказа уникальной цветочной композиции пользователь регистрируется на портале «iFlower.ru». Пользователь вводит базовую информацию при регистрации на сайте магазина и указывает виды цветов, которые должны войти в букет.

Задача:
К Вам обратилась администрация цветочного магазина с просьбой разработать сервис по генерации различных вариантов цветочной композиции для пользователя. Сервис должен анализировать введенные пользователем данные и формировать три варианта букета, на выбор пользователя.

Ответьте развернуто на следующие вопросы:
а) Как Вы видите сценарии работы данного сервиса?
б) Как бы Вы собирали первичный набор данных и из чего он должен состоять, чтобы сформировать итоговое предложение для пользователя?
в) Как бы Вы строили работу по созданию базового набора данных? Из каких открытых источников Вы бы собирали информацию?
г) На основе каких данных Вы бы формировали предложения для пользователя?
